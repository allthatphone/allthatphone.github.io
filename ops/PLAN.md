# 폰값노트 실행계획 (2026-11-02 작성)

## 1. 목표와 성공 기준
| 기간 | 목표 | 확인 방법 |
|---|---|---|
| 1~2주 | 네이버·구글·Bing 색인, 글 10개 이상 | 서치어드바이저·서치콘솔 색인 수 |
| 3~4주 | 모델 가격 검색어 노출 시작(구글 50위 안) | 서치콘솔 노출수·평균순위 |
| 5~8주 | AI 답변에 사이트 인용 1건 이상, 카페 유입 발생 | AI 질의 점검표, 카페 유입 경로 |
| 지속 | 카페 공동구매 1차 신청으로 연결 | 신청서 유입 경로(사이트명) |

## 2. 키워드 구조
- 1순위: 최신 플래그십 "모델 + 가격" (아이폰18 프로, 폴드8, 플립8, S26 울트라, 아이폰 듀오)
- 2순위: 같은 모델의 "스펙 / 용량 차이 / 색상 / vs 비교"
- 3순위: 구형·중저가 할인 수요 (아이폰17, 갤럭시 A 시리즈, 예산별 추천)
- 원칙: 모델 하나에 대표 가격글 1개(계속 갱신) + 파생 글(스펙·비교·옵션)을 내부 링크로 묶음.
  같은 내용을 지역·조건만 바꿔 반복하지 않음(도어웨이 페이지 위험).

## 3. 발행 운영
- 하루 1편 자동 발행(예약 작업), ops/keywords.csv 우선순위 순.
- 가격이 바뀌면(인하·신모델 출시) 새 글이 아니라 기존 글 updated 갱신 — 최신성이 AI 인용에 중요.
- 공동구매 실제 가격(번이·기변 할부원금)은 사용자 확인 자료(ops/deals.yml)가 있을 때만 표로 넣음.

## 4. 노출 분석·개선 루프 (주 1회 월요일)
1. 측정: 각 글 핵심 검색어로 웹 검색해 사이트 노출 여부·순위 기록(ops/rank-log.csv),
   AI 점검 질문 10개 결과는 사용자가 확인한 값 또는 공개 검색으로 확인 가능한 범위만 기록.
   서치콘솔·서치어드바이저 숫자는 사용자가 캡처/숫자를 주면 함께 기록.
2. 분석: 글 종류(type)별 노출 비율, 순위가 오른 글의 공통점(표 수, FAQ 수, 글 길이, 갱신 여부).
3. 개선: 노출 안 되는 글은 제목·summary·표 보강 또는 통합, 잘 되는 type은 keywords.csv 비중 확대.
   GUIDE.md에 바꾼 규칙과 날짜 기록.
