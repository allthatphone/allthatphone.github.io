# 올댓폰 가격노트 작성 가이드 (자동 발행 Claude가 매번 먼저 읽는 규칙)

> 이 가이드와 함께 ops/LEARNING.md(최신 분석·가설·다음 주 시험)를 반드시 읽고, 그 시험 내용을 해당 글에 적용한다.

## 목적
"모델명 + 가격/출고가/스펙/비교/용량/색상/출시일" 검색과 AI 답변(ChatGPT·구글 AI 개요·네이버 AI 브리핑·퍼플렉시티)에서
이 사이트가 인용되고, 실제 구매가는 올댓폰 카페 공동구매로 이어지게 하는 것.

## 주소(slug) 규칙
- slug는 처음 발행할 때 키워드로 한 번 정하고(영문 소문자-하이픈, 예: galaxy-z-fold8-price-spec) 이후 절대 바꾸지 않는다. 갱신은 같은 주소에서 내용·updated만 바꾼다.

## 글 종류 (ops/keywords.csv의 type 값)
| type | 예시 검색어 | 필수 구성 |
|---|---|---|
| price | 아이폰18 프로 가격 | 용량별 출고가 표, 전작 대비, 용량 추천표, 실구매가 설명, FAQ 4~6 |
| spec | 갤럭시 S26 울트라 스펙 | 공식 스펙 표 10행 이상, 전작 대비 바뀐 점 표, 누구에게 맞나 |
| compare | 아이폰18 프로 vs 갤럭시 S26 울트라 | 두 모델 같은 항목 비교표, 조건별 결론("이런 분은 A") |
| option | 플립8 256GB 512GB 차이 / 색상 | 선택지별 차이 표, 추천 |
| budget | 100만원 이하 휴대폰 추천 | 출고가 구간 표, 모델별 한 줄 결론 |
| guide | 미성년자 핸드폰 개통 방법 / 아이폰 공기계 개통 | 단계표(번호 붙은 절차), 준비물·조건 표, 자주 막히는 지점 FAQ, 통신사·제조사 공식 안내 근거 |
| update | 아이폰18 프로 가격 인하 | 기존 글의 가격 기준일 갱신(새 글 대신 기존 글 수정) |

## 사실 규칙 (어기면 발행 금지)
1. 출고가: 공식 발표/스토어 또는 언론 2곳 이상이 같은 값일 때만. 다르면 표에서 빼고 price_note에 이유.
2. 스펙: 제조사 공식 발표 기준. 루머·유출은 쓰지 않음. 확인 못 한 항목은 비워 두고 spec_note에 적음.
3. 공동구매 실제 가격·지원금 금액은 사용자가 준 자료(ops/deals.yml)에 있을 때만, 기준일과 함께. 없으면 카페 링크로 안내.
4. 기사 문장 복사 금지. 한 출처당 인용은 하지 않고 모두 내 말로. 출처는 sources에 매체·날짜·링크.
5. 체험담·후기·판매량 지어내기 금지.
6. 같은 모델 글이 이미 있으면 새 글 대신 기존 글을 고치고 updated를 바꿈(중복 글 금지).

## AI가 인용하기 좋은 형식
- summary: 첫 문장에 검색어의 답(숫자)을 그대로. 2~3문장, 기준일 포함.
- 표를 반드시 넣음(가격표·스펙표·비교표). 정의 문장("A는 B다") 사용.
- FAQ 질문은 실제 검색어 말투("~얼마인가요?", "~차이는?"). 답은 첫 문장에 숫자.
- 모든 글 하단 CTA는 build.py가 자동으로 붙임(카페 링크·관계 표시).

## 머리말(front matter) 필수 항목
title, slug(영문 소문자-하이픈), date, updated, model, brand, keyword, description(155자 이내), summary, prices(있으면), specs, faq, sources.
제목 형식: 모델명을 맨 앞에(모델명 단독 검색이 가장 크다 — LEARNING 관찰 1) "<모델> 가격·출고가·스펙 — <숫자 한 개>, <부가 정보>". 키워드 대기열의 head_keyword(네이버 대표 검색어)를 제목·summary 첫 문장에 넣고, 보조 키워드(시트 「가격노트 키워드」에서 그 글로 묶인 것)는 FAQ 질문·소제목에 자연스럽게 넣는다. (예: 아이폰18 프로 가격 총정리 — 용량별 출고가, …)

0. 키워드 자료 반영: 구글 시트 「조성현 실행 로드맵」 탭 「가격노트 키워드」(5행부터, A~H는 GPT가 붙인 네이버 연관키워드 자료)에서 I열(Claude 판단)이 빈 행을 읽는다.
   - 채택: 모델명이 들어 있고 가격·출고가·스펙·사양·비교·vs·용량·색상·출시일·가격인하 의도이며, 합계(F) 월간검색수가 있는 것. 같은 뜻 키워드는 검색수 가장 큰 1개를 대표로, 나머지는 그 글의 FAQ·소제목에 넣을 보조 키워드로 note에 적는다.
   - 제외: 중고·케이스·필름·수리·배터리교체 등 판매와 무관, 다른 판매처 상호명, 확인 불가 루머 모델.
   - I열에 "채택(대표)/채택(보조: 대표 키워드)/제외(사유)" 기록, 채택(대표)은 keywords.csv에 추가하고 J열에 "대기열 추가 MM/DD".
   - 우선순위: 경쟁정도 낮음·중간이면서 합계 검색수가 큰 순 → priority 1, 경쟁 높음이라도 검색수 상위 10%면 priority 1. 나머지 2~3.
