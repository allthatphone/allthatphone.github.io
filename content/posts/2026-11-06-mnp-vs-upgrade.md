**스마트폰 기기변경**은 쓰던 통신사와 번호를 그대로 두고 단말기만 새로 바꾸는 가입 방식이고, **번호이동**은 휴대폰 번호는 유지하면서 SKT·KT·LG U+ 중 다른 통신사로 옮기는 방식입니다. 둘 다 "새 폰을 산다"는 점은 같지만, 번호이동은 기존 통신사 계약이 끝나기 때문에 받을 돈과 잃을 돈이 함께 생깁니다.

## 기기변경·번호이동·신규가입 한눈에 비교

| 항목 | 기기변경 | 번호이동 | 신규가입 |
|---|---|---|---|
| 통신사 | 그대로 | 바뀜 | 새로 가입 |
| 전화번호 | 그대로 | 그대로 | 새 번호 |
| 기존 통신사 계약 | 이어짐 | 자동 해지 | 기존 회선과 별개 |
| 결합할인·장기고객 혜택 | 대체로 유지 | 기존 통신사 것은 사라짐 | 해당 없음 |
| 기존 약정 위약금·할인반환금 | 약정 조건에 따라 생길 수 있음 | 남은 약정이 있으면 정산 | 해당 없음 |
| 남은 할부금 | 계속 납부 | 완납하거나 분납 유지 선택 | 해당 없음 |
| 다시 옮길 수 있는 시점 | 제한 없음(통신사 안 이동) | 3개월 동안 번호이동 제한 | 3개월 동안 번호이동 제한 |
| 이용 수수료 | — | 800원(SKT 안내 기준) | — |

번호이동 제한·수수료·절차는 SKT T world 번호이동 안내를 기준으로 정리했습니다. 3개월 제한은 특정 통신사 규칙이 아니라 번호이동 제도 전체에 적용되는 원칙입니다.

## 단통법 폐지 후 — 번호이동·기기변경 지원금을 다르게 줄 수 있다

| 시기 | 가입 유형별 지원금 | 번호이동 전용 지원 |
|---|---|---|
| 2024년 3월 13일까지 | 같은 요금제면 차등 금지 | 없음 |
| 2024년 3월 14일 ~ 2025년 7월 21일 | 공시지원금은 차등 금지 | 전환지원금 최대 50만원(위약금·유심 발급비·장기가입 혜택 상실분 보전 명목) |
| 2025년 7월 22일 이후(단통법 폐지) | 번호이동·기기변경·신규 차등 허용 | 별도 상한 없음, 통신사·판매점이 정함 |

단통법 폐지 뒤에도 지역·나이·신체 조건에 따른 차별, 특정 요금제 강요, 지원금을 부풀려 설명하는 행위는 계속 금지됩니다. 비싼 요금제에 지원금을 더 주는 것은 되지만, 그 요금제를 쓰라고 강제하는 것은 안 됩니다. 페이백 같은 혜택은 모두 계약서에 적혀야 하고, 말로만 약속하는 방식은 금지됐다고 보도됐습니다(뉴시스 2025년 7월 18일).

정리하면 지금은 **"번호이동이 무조건 더 싸다"는 규칙이 없습니다**. 같은 모델·같은 요금제로 번호이동 견적과 기기변경 견적을 각각 받아야 비교가 됩니다.

## 번호이동이 이득인지 계산하는 법 — 받는 돈에서 잃는 돈을 뺀다

번호이동 견적이 기기변경보다 싸 보여도, 기존 통신사를 떠나면서 사라지는 것을 빼야 실제 차이가 나옵니다.

| 항목 | 넣는 값 | 확인하는 곳 |
|---|---|---|
| ① 지원금 차이 | 번호이동 지원금 − 기기변경 지원금 | 두 견적서(같은 모델·요금제) |
| ② 잃는 결합할인 | 월 결합할인 × 앞으로 쓸 개월 수 | 기존 통신사 요금 명세서 |
| ③ 잃는 장기고객 혜택 | 데이터 쿠폰·멤버십 등급 혜택 등 | 기존 통신사 앱 |
| ④ 위약금·할인반환금 | 남은 선택약정·지원금 약정 정산액 | 사전 동의 문자 안내, 고객센터 |
| ⑤ 가족 결합에 묶인 회선 | 내 회선이 빠지면 가족 할인이 줄어드는지 | 결합 상품 안내 |

**판단식: ① − (② + ③ + ④ + ⑤) > 0 이면 번호이동이 이득**입니다.

예를 들어(설명용 가정) 번호이동 지원금이 기기변경보다 20만원 많아도, 월 1만원 결합할인을 24개월 잃으면 ②만 24만원이라 오히려 4만원 손해입니다. 반대로 결합할인이 없고 약정도 끝난 회선이면 ②~⑤가 거의 0이라 ①이 그대로 이득이 됩니다.

선택약정 25% 할인을 받고 있는 회선은 ④를 꼭 확인하세요. 할인반환금 구조와 자급제폰으로 바꿀 때의 계산은 [자급제 vs 통신사 구매 비교](https://allthatphone.github.io/unlocked-vs-carrier/)에 정리했습니다.

## 이런 분은 기기변경, 이런 분은 번호이동

| 내 상황 | 유리한 쪽 | 이유 |
|---|---|---|
| 집 인터넷·TV와 결합할인을 받고 있음 | 기기변경 우선 검토 | 번호이동하면 결합 구성이 깨져 ②·⑤가 커짐 |
| 가족 결합의 대표 회선 | 기기변경 우선 검토 | 내 회선만 빠져도 가족 전체 할인이 줄 수 있음 |
| 약정·할부가 모두 끝남, 결합 없음 | 번호이동 견적도 받아 볼 것 | 잃을 혜택이 적어 지원금 차이가 그대로 이득 |
| 3개월 안에 번호이동·신규가입·명의변경을 했음 | 기기변경 | 원칙적으로 번호이동 제한 기간 |
| 지금 통신사 통화 품질이 불만 | 번호이동 | 통신사 자체를 바꾸는 것이 목적 |
| 요금 체납이 있음 | 기기변경(체납 정리 후) | 체납 중에는 번호이동 대상에서 빠짐 |
| 자급제폰을 이미 샀음 | 유심 기기변경 | 단말 지원금이 없어 번호이동 이점이 줄어듦, 선택약정으로 요금 할인 |

모델을 먼저 정했다면 출고가부터 확인하세요. 같은 지원금이라도 출고가가 다르면 할부원금이 달라집니다. [갤럭시 S26 가격](https://allthatphone.github.io/galaxy-s26-price-spec/), [아이폰17 가격](https://allthatphone.github.io/iphone-17-price-spec/), [갤럭시 Z플립8 가격](https://allthatphone.github.io/galaxy-z-flip8-price-spec/)에 용량별 출고가 표가 있습니다.

## 번호이동 절차 — 기존 통신사는 따로 해지하지 않는다

1. **견적 비교** — 같은 모델·요금제로 번호이동 견적과 기기변경 견적을 받아 위 판단식에 넣습니다.
2. **가입 신청** — 옮겨 갈 통신사 매장·대리점·온라인몰에서 가입 신청서를 씁니다. 신분증이 필요하고, 대리인은 위임장이 있으면 신청할 수 있습니다.
3. **사전 동의 요청** — 기존 통신사에서 사전 동의 문자를 받습니다. 문자를 받을 수 없는 상황이면 ARS로 진행합니다.
4. **해지 내용 확인·동의** — 문자 속 링크나 ARS에서 해지되는 계약과 사라지는 혜택을 확인하고 동의합니다. 이 단계가 ②~⑤를 최종 확인하는 자리입니다.
5. **할부금 처리 선택** — 기존 폰의 남은 할부금은 완납하거나 계속 나눠 내기를 고릅니다.
6. **개통 완료** — 새 통신사로 번호가 옮겨지고 기존 통신사 서비스는 자동으로 해지됩니다.

기존 통신사 대리점에서 먼저 해지해 버리면 번호이동이 안 되니 순서를 지켜야 합니다. SKT 안내 기준으로 번호이동 후 14일(휴일 포함) 이내에는 통화 품질 등을 이유로 철회할 수 있고, 철회하면 3일 안에 기존 통신사에서 다시 가입해야 같은 번호를 이어 쓸 수 있습니다.

## 번호이동이 안 되는 경우 — 제한 규칙

| 제한 | 내용 | 예외·해결 |
|---|---|---|
| 3개월 재이동 제한 | 번호이동·신규가입·명의변경 뒤 3개월 동안 번호이동 불가 | KTOA 번호이동관리센터에 '제한기간 이내 번호이동' 직접 신청 |

| 요금 체납 | 번호이동 시점에 체납이 있으면 불가 | 체납 정리 후 진행 |
| 선불·임대폰 | 번호이동 대상 아님 | 후불 회선으로 전환 |
| 기존 통신사 선해지 | 미리 해지하면 번호이동 불가 | 해지하지 말고 새 통신사에서 신청 |

## 통신사별(SKT·KT·LG U+) 번호이동·기기변경, 공통으로 확인할 것

번호이동 제도(사전 동의, 3개월 제한)는 통신 3사 공통입니다. 통신사마다 달라지는 것은 지원금 금액과 조건이라, SKT 번호이동·KT 번호이동·유플러스(LG U+) 번호이동 어느 쪽이든 아래 네 가지를 견적서에서 같은 형식으로 받아 두면 비교가 쉽습니다.

| 견적서에서 받을 것 | 왜 필요한가 |
|---|---|
| 단말 할부원금(출고가 − 지원금) | 실제 단말값 비교 기준 |
| 요금제와 유지해야 하는 기간 | 고가 요금제 유지 조건이 붙으면 그 차액도 비용 |
| 부가서비스 가입 조건과 해지 가능 시점 | 숨은 월 비용 확인 |
| 중도 해지 때 위약금 계산 방식 | 1~2년 안에 바꿀 가능성 대비 |

KT 기기변경·SKT 기기변경처럼 같은 통신사에 남는 경우에도 단통법 폐지 뒤에는 기기변경 전용 조건이 따로 나올 수 있으니, "번호이동이면 얼마, 기기변경이면 얼마"를 한 번에 물어보는 것이 가장 빠릅니다.

## 아이폰 기기변경·번호이동 — 자급제로 사면 달라지는 점

아이폰을 통신사에서 사면 기기변경과 번호이동 견적이 각각 나오지만, 애플 스토어 등에서 **자급제 아이폰**을 사면 단말 지원금이 없으므로 대부분 '유심 기기변경'으로 끝납니다. 쓰던 유심을 옮기거나 eSIM을 새로 받으면 번호·통신사가 그대로 유지되고, 원하면 선택약정 25%를 새로 걸 수 있습니다. 자급제로 사서 통신사까지 바꾸고 싶다면 새 통신사 유심이나 eSIM으로 번호이동 가입을 하면 됩니다.
