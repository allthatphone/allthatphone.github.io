  - q: 휴대폰개통조회는 어디서 하나요?

**한 줄 결론:** 휴대폰개통조회는 **엠세이퍼(msafer.or.kr) → 가입사실현황조회** 한 곳에서 무료로 끝납니다. 그리고 **2026년 11월 20일부터** 신규가입·번호이동·명의변경을 하면 가입제한서비스가 **기본으로 걸리고 모든 통신사에 한 번에 적용**되므로, 다음 개통 전에는 "조회 → 제한 상태 확인 → 해지 → 개통 → 재신청" 순서를 기억해 두면 됩니다.

이 글은 '내 명의로 무엇이 개통돼 있는지'를 확인하고 막는 방법만 다룹니다. 개통 자체의 준비물(신분증·안면인증)은 [핸드폰 개통 방법](https://allthatphone.github.io/phone-activation-guide/)에, 통신사를 옮기는 절차는 [SKT번호이동 방법](https://allthatphone.github.io/carrier-mnp-guide/)에 정리해 두었습니다.

## '개통 조회'는 두 가지 — 먼저 어느 쪽인지 고르기

| 알고 싶은 것 | 보는 곳 | 결과로 나오는 것 |
|---|---|---|
| 내 명의로 개통된 회선이 몇 개·어디에 있나 | 엠세이퍼 가입사실현황조회 | 이동전화·유선·인터넷·알뜰폰 가입 내역 |
| 내가 방금 신청한 개통이 끝났나 | 신청한 통신사 온라인몰 주문 조회·판매처 안내 문자 | 주문·배송·개통 진행 상태 |
| 앞으로 내 명의 개통을 막고 싶다 | 엠세이퍼 가입제한서비스 | 신규가입·번호이동·명의변경 차단 |
| 내 명의로 새 회선이 생기면 바로 알고 싶다 | 엠세이퍼 신규가입 알림 | 내 명의 휴대폰으로 문자(못 받으면 등기우편) |

검색창에 '휴대폰개통조회'·'핸드폰개통조회'를 치는 사람은 대부분 첫째 줄, 즉 **명의도용 확인**이 목적입니다. 아래 단계는 그 기준입니다.

## 휴대폰개통조회 5단계 (엠세이퍼 가입사실현황조회)

| 단계 | 할 일 | 막히는 지점 |
|---|---|---|
| 1 | 엠세이퍼 홈페이지(msafer.or.kr) 또는 PASS·카카오뱅크 앱의 명의도용방지서비스 메뉴 열기 | 11월 20일 오전 9시 전에는 KT·LG U+ PASS와 카카오뱅크가 중단 중 → 홈페이지나 SKT PASS로 |
| 2 | '가입사실현황조회' 선택 | '가입제한서비스'와 메뉴가 나란히 있어 헷갈리기 쉬움 |
| 3 | 본인확인(약관 동의 → 본인인증) | 회원가입은 필요 없음. 본인 명의 인증수단이 없으면 진행 불가 |
| 4 | 가입 내역 확인 — 이동전화·유선·인터넷·알뜰폰 | 통신사·회선 수가 내가 아는 것과 같은지 한 줄씩 대조 |
| 5 | 모르는 회선이 있으면 그 통신사에 명의도용 신고 + 가입제한 신청 | 신고·제한 신청은 본인만 가능(대리 불가) |

조회는 무료이고, 전화·이메일로 대신 조회해 주지는 않습니다. 가족 회선을 내 명의로 개통해 준 적이 있다면(부모님 효도폰, 자녀 키즈폰 등) 그 회선도 내 명의로 나오니, 결과를 보기 전에 "내가 만들어 준 회선"을 먼저 적어 두면 대조가 빠릅니다.

## 11월 20일부터 바뀌는 가입제한서비스 — 전과 후

| 항목 | 11월 19일까지 | 11월 20일부터 |
|---|---|---|
| 가입 방식 | 본인이 직접 신청해야 걸림 | 신규가입·번호이동·명의변경 때 기본으로 걸림 |
| 거부 | — | 개통 단계에서 거부 가능, 불이익 없음 |
| 적용 범위 | 통신사별로 골라 신청·해지 | 한 곳에서 신청하면 **모든 통신사**에 적용(일괄) |
| 대상 사업자 | 이동통신 3사 중심 | 이동통신 3사 + 알뜰폰 사업자 |
| 이미 쓰던 회선(기존 가입자) | — | 자동 적용 안 됨 → 원하면 직접 신청 |
| 신청·해지 창구 | 엠세이퍼·PASS·카카오뱅크·통신사 지점 | 엠세이퍼·PASS·카카오뱅크·통신사 직영점 |
| 신청·해지 시간 | — | 오전 9시~오후 10시 |
| 대리 처리 | — | 불가(본인만) |

근거는 전기통신사업법 제32조의6 개정이고, 디지털투데이 보도에 따르면 통신사는 계약 전에 기본 제공 사실·거부할 권리·주요 내용·해지 방법을 알려야 합니다. 예전 글에서 "해제는 각 통신사 지점에서"라고 안내하던 부분은 11월 20일부터 일괄 해지 방식으로 바뀝니다.

## 가입제한이 걸린 상태에서 막히는 것

| 하려는 일 | 가입제한 걸려 있으면 | 해야 할 순서 |
|---|---|---|
| 다른 통신사로 번호이동 | 막힘 | 해지 → 번호이동 → 재신청 |
| 새 번호 신규가입(세컨폰·태블릿 회선 등) | 막힘 | 해지 → 신규가입 → 재신청 |
| 명의변경(가족 회선 넘겨받기) | 막힘 | 해지 → 명의변경 → 재신청 |
| 같은 통신사 기기변경 | 엠세이퍼 공지에 제한 대상으로 적혀 있지 않음 | 온라인몰은 별도 조건 확인(KT닷컴은 엠세이퍼 가입 시 온라인 기기변경 제한을 안내) |

번호이동 날짜를 잡았다면 **신청 전날까지 해지해 두는 것**이 가장 안전합니다. 신청·해지는 오전 9시~오후 10시에만 되므로, 밤늦게 온라인 번호이동을 하려다 막히면 다음 날 9시까지 기다려야 합니다. 번호이동 사전동의 단계에서 멈추는 경우도 원인이 같을 수 있으니 [SKT번호이동 방법](https://allthatphone.github.io/carrier-mnp-guide/)의 제한 조건 표와 함께 보세요. 같은 통신사에 남는다면 [KT기기변경 방법](https://allthatphone.github.io/carrier-upgrade-guide/)에 온라인 기기변경 제한 조건을 따로 적어 두었습니다.
