개통 가이드기준일 2026-11-21

휴대폰 온라인 개통 방법 — 공식몰 주문부터 셀프개통·자동개통까지 통신 3사 비교

한눈에 보는 답휴대폰 온라인 개통은 통신사 공식 온라인몰에서 주문하고 서류 심사를 거쳐 폰을 받은 뒤, 문자로 온 링크나 주문서로 직접 개통(셀프개통)하는 방식입니다. 2026년 11월 21일 확인 기준 SK텔레콤 T 다이렉트샵은 월~토 오후 6시 전에 주문·심사가 끝나면 당일 배송하고, 직접 개통하지 않으면 배송 2일 뒤 오전 9시부터 자동 개통합니다. KT 다이렉트샵 유심 셀프개통은 신규가입 8~20시, 번호이동 10~20시(평일·토요일)에만 처리되고 일요일·명절 당일은 쉽니다.

한 줄 결론: 휴대폰 온라인 개통은 '주문 → 서류 심사 → 배송 → 셀프개통' 4단계이고, 늦어지는 지점은 거의 항상 '심사 완료 시각'과 '셀프개통 처리 시간'입니다. SK텔레콤은 월~토 오후 6시 전에 심사가 끝나야 당일 배송되고, KT 유심 셀프개통은 번호이동이 오전 10시~오후 8시에만 처리됩니다. 이 두 시각만 알고 주문하면 "폰은 왔는데 개통이 안 된다"는 상황 대부분을 피할 수 있습니다.

준비물(신분증·추가 본인 확인)과 개통 종류별 차이는 핸드폰 개통 방법에 먼저 정리했습니다. 이 글은 통신사 공식 온라인몰에서 사서 집에서 개통하는 경우만, 통신사별 시간표와 막히는 지점 위주로 다룹니다.

온라인 개통이 매장보다 빠른 경우는 많지 않습니다. 대신 매장에서 요금제·부가서비스 권유를 받지 않고, 표시된 조건 그대로 산다는 점이 차이입니다. 실구매가 자체를 비교하려면 휴대폰 싸게 사는 법과 공시지원금 vs 선택약정을 같이 보세요.

휴대폰 온라인 개통 4단계 — 단계마다 걸리는 시간

단계 하는 일 걸리는 시간·기준 여기서 막히는 경우
1. 주문 모델·용량·요금제·가입 방식(신규·번호이동·기기변경)·할인 방식 선택 수 분 90일 이내 번호이동·기기변경 이력(KT는 온라인 가입 제한)
2. 서류 심사 본인 확인, 신규·번호이동은 추가 인증(안면인증·모바일 신분증·당일 초본 중 하나) 영업시간 안에서 처리 가입제한서비스 켜짐, 요금 미납, 명의 정보 불일치
3. 배송 택배·당일 배송·방문 배송 중 선택 SKT 바로도착: 월~토 18시 전 심사 완료 시 당일 토요일 오후·일요일 심사 완료 → 월요일 배송
4. 셀프개통 문자 링크 또는 주문서로 개통 신청 → 완료 문자 → 유심 장착·재부팅 처리 시간 안이면 바로 일요일·명절 당일, 번호이동 오전 10시 전

SKT 온라인 개통 — T 다이렉트샵 배송·셀프개통 기준

SK텔레콤 공식 온라인몰은 T 다이렉트샵입니다. 2026년 11월 21일 T world 자주하는 질문 기준으로 정리했습니다.

배송 방식 당일 배송 기준(주문+서류 심사 완료) 기준 시각 이후 특징
바로도착 월~토 오후 6시 전 평일 → 다음 날 / 토 오후 5시 이후~일 → 월요일 일반 배송보다 빠른 당일 배송, 전국(일부 지역 제외)
행복배송 월~토 오후 3시 전 평일 → 다음 날 / 토 오후 3시 이후~일 → 월요일 T 크루가 방문해 개통·데이터 이전·중고폰 보상까지 도움

배송 가능 지역은 주문 화면에서 주소로 확인하고, 시간은 주문 마지막 단계에서 고릅니다. 기사가 출발한 뒤에는 시간을 바꿀 수 없습니다.

SKT 셀프개통 순서

  1. 폰을 받은 뒤 문자로 온 주소로 접속해 로그인합니다.
  2. 개통 신청을 누릅니다(기기변경·유심 새로 구매·번호이동·신규가입 모두 같은 화면).
  3. 개통 완료 문자를 받은 다음 유심을 넣습니다. 문자 전에 넣지 않습니다.
  4. 휴대폰을 1~2번 껐다 켭니다.

쓰던 유심을 그대로 쓰는 기기변경은 따로 신청하지 않고, 기존 유심을 새 폰에 옮겨 끼운 뒤 재부팅하면 됩니다. 법인·외국인 명의는 셀프개통이 아니라 T 다이렉트샵 고객센터 전화로 신청합니다.

휴대폰 온라인 개통이 막히는 지점 5가지

  1. 가입제한서비스가 켜져 있음 — 2026년 11월 20일부터 개통 때 기본으로 켜집니다. KT는 셀프개통 전에 PASS 앱이나 엠세이퍼에서 온라인 가입 제한을 풀라고 안내합니다. 내 명의 회선 확인은 휴대폰 개통 조회 방법 참고.
  2. 개통 완료 문자 전에 유심을 넣음 — SKT는 완료 문자를 받은 뒤 넣으라고 안내합니다. 이미 넣었다면 문자 확인 후 다시 재부팅합니다.
  3. 처리 시간 밖에 신청함 — 저녁 8시 이후·일요일 신청은 다음 영업일에 처리됩니다.
  4. 자동 개통을 잊음 — 데이터를 옮기기 전에 자동 개통되면 이전 폰 유심이 끊깁니다. 백업은 폰 받은 날 끝내 두세요.
  5. 추가 본인 확인 실패 — 신규·번호이동은 안면인증·모바일 신분증·당일 주민등록초본 중 하나가 필요합니다. 추가 인증을 한 주문은 배송도 본인이 직접 받아야 한다고 KT는 안내합니다.

모델 가격과 실제 구매가

온라인몰 가격은 출고가에서 몰에 표시된 지원금을 뺀 값입니다. 모델별 출고가는 아이폰 가격·갤럭시 S26 가격·갤럭시 A17 가격에 정리했습니다. 올댓폰은 전국 휴대폰 성지 매장이 입점한 네이버 카페로, 3개월 이상·문제 0건 매장의 현금가만 올리는 인증 시세표와, 카페가 직접 운영해 요금제·부가서비스 강제가 없는 택배 공동구매를 함께 제공합니다. 택배 공동구매도 폰을 받은 뒤 개통하는 구조라 이 글의 '처리 시간·자동 개통' 주의점이 그대로 통합니다. 입점 매장 구매는 매장별 조건이 있을 수 있습니다. 자세한 방식은 휴대폰 공동구매란에 있습니다.

휴대폰 온라인 개통(통신사 공식 온라인몰) 실제 구매가가 궁금하다면
출고가는 시작점일 뿐이고, 실제로 내는 돈은 통신사·가입 방법(번호이동/기기변경)·요금제 조건에 따라 달라집니다. 올댓폰 카페에서는 요금제·부가서비스를 강제하지 않는 SKT·KT·LG U+ 온라인 공동구매 가격을 모델별로 공개합니다.
휴대폰 온라인 개통(통신사 공식 온라인몰) 공동구매 가격 보기 이 사이트의 공동구매 안내는 운영자와 관련된 올댓폰 카페 게시글을 기준으로 합니다.

자주 묻는 질문

휴대폰 온라인 개통은 어떤 순서로 하나요?

공식 온라인몰에서 폰·요금제·가입 방식(신규·번호이동·기기변경) 선택 → 본인 확인과 서류 심사 → 배송 수령 → 셀프개통 신청 → 개통 완료 문자 확인 후 유심 장착·재부팅 순서입니다. SK텔레콤은 개통 완료 문자를 받기 전에는 유심을 넣지 말라고 안내합니다.

휴대폰온라인구매 후 개통을 안 하면 어떻게 되나요?

정해진 기간이 지나면 통신사가 자동으로 개통합니다. SK텔레콤 T 다이렉트샵은 휴대폰 배송 2일 후 오전 9시부터 순차 개통(토·일·공휴일 제외), KT 다이렉트샵 유심 번호이동은 수령일 포함 3일까지 요청이 없으면 자동 개통됩니다. 자동 개통 뒤에는 이전 통신사 유심을 쓸 수 없으니 그 전에 데이터 백업을 끝내 두세요.

셀프개통은 밤이나 일요일에도 되나요?

안 됩니다. 신청 화면은 언제든 열리지만 실제 개통 전산은 정해진 시간에만 돕니다. KT 다이렉트샵은 신규가입 8~20시·번호이동 10~20시(평일·토요일)이고 일요일과 신정·설·추석 당일은 처리하지 않습니다. SK텔레콤은 기기변경·신규가입 월~토 8~20시, 번호이동 월~토 10~20시입니다.

핸드폰온라인구매하면 다음 날 바로 받을 수 있나요?

SK텔레콤 T 다이렉트샵 '바로도착'은 월~토 오후 6시 전에 주문과 서류 심사가 끝나면 당일 배송, 평일 6시 이후면 다음 날, 토요일 오후 5시 이후부터 일요일까지 끝나면 월요일 배송입니다. 주문 시각이 아니라 '심사 완료 시각'이 기준이라 서류가 늦게 통과되면 하루 밀립니다.

온라인으로 산 폰을 매장에서 개통해 달라고 할 수 있나요?

SK텔레콤은 T 다이렉트샵에서 산 휴대폰을 SK텔레콤 매장에서 임의로 개통할 수 없다고 안내합니다. 혼자 하기 어렵다면 T 다이렉트샵 고객센터(평일 9~19시, 토요일 10~19시)로 개통을 요청하거나, 기사가 방문해 개통과 데이터 이전을 돕는 '행복배송'을 고르는 편이 맞습니다.

온라인 개통이 막히는 가장 흔한 이유는?

가입제한서비스(엠세이퍼·PASS)가 켜져 있거나, 최근 90일 안에 번호이동·기기변경을 했거나, 통신 요금 미납이 남은 경우입니다. KT는 셀프개통 전에 이 세 가지를 먼저 풀라고 안내하고, 90일 이내 번호이동·기기변경은 온라인 가입 자체를 제한합니다. 2026년 11월 20일부터 가입제한서비스가 개통 때 기본으로 켜지므로 새 회선이면 특히 확인하세요.

미성년자도 온라인으로 셀프개통할 수 있나요?

KT 다이렉트샵 유심 셀프개통은 만 19세 이상 본인 신청만 받습니다. 미성년자는 법정대리인 동의 서류가 필요해 매장 개통이 일반적이며, 준비물은 미성년자 개통 글에 따로 정리했습니다.

eSIM으로 온라인 개통하면 더 빠른가요?

유심 배송을 기다리지 않아도 되므로 빠릅니다. KT 다이렉트샵은 eSIM 가능 여부 확인 → 요금제·주문서 작성 → QR코드 스캔 설치 3단계이며, 지원 기종은 아이폰 XS 이상, 갤럭시 S23 시리즈 이상·Z4 시리즈 이상·A35 시리즈 이상입니다.
